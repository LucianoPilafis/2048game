# 2048 Game - Project Structure & Organization

## 📋 Overview

This is a **2048 game implementation** built with **autonomous agent-driven development** using the ADW (AI Developer Workflows) pattern. The project demonstrates plan → build → test workflows with agent-driven GitHub issues, PRs, and commits.

**Technology Stack:**
- Frontend: React 18 + TypeScript 5
- Build Tool: Vite 5
- Testing: Vitest
- Deployment: Vercel
- Development: Agent-driven workflows

## 🔄 Workflow: How ADWs Work

### Feature Development Cycle

```
GitHub Issue Created
        ↓
Agent Assigned (via ADW command)
        ↓
Plan Phase (adw_plan.py)
  - Design feature
  - Break into tasks
  - Identify files to modify
        ↓
Build Phase (adw_build.py)
  - Write code
  - Implement changes
  - Commit to branch
        ↓
Test Phase (adw_test.py)
  - Run test suite
  - Validate E2E tests
  - Fix issues
        ↓
PR Created (automatic)
        ↓
Merged to main
```

### Key ADW Commands

| Command | File | Purpose |
|---------|------|---------|
| `/feature "name"` | feature.md | Start new feature |
| `/bug "description"` | bug.md | Fix a bug |
| `/chore "task"` | chore.md | Maintenance work |
| `/implement "task"` | implement.md | Implement specific task |
| `/test` | test.md | Run test suite |
| `/review` | review.md | Code review |
| `/commit` | commit.md | Generate commit |
| `/pull_request` | pull_request.md | Create PR |

## 🔑 Key Concepts

### ADW (AI Developer Workflows)
- Autonomous workflows that plan, build, test, and review code
- Each workflow phase is orchestrated by Python scripts
- Agents track state in `agents/` directory
- Results captured in `specs/` and commit history

### State Management
- Game state managed in `src/game/logic.ts`
- Theme/palette state via React Context (`src/themes/ThemeContext.tsx`)
- Agent execution state in `adws/adw_modules/state.py`

### Component Architecture
- `Game.tsx` - Main board rendering
- `Tile.tsx` - Individual tile display
- `PaletteSelector.tsx` - UI for theme selection
- `ThemeContext.tsx` - Global theme provider
